# 🏆 BSD Sport — Ici, le sport nous rassemble (Vue 3 + Tailwind CSS)

Application Web officielle de **BSD Sport** entièrement convertie depuis `bsd-sport-accueil_5.html` sous **Vue 3**, **Vite**, **Tailwind CSS**, **Pinia** et **Vue Router**.

---

## ⚡ Caractéristiques & Animations

- **Hero & Stickmen Athlètes** : Titre géant *Anton* avec bonshommes stickmen animés sur les lettres (balançoire pendule sur le 'T', coureur, grimpeur sur le 'N', boxeur sur le 'E').
- **8 Univers Athlétiques** : *Cross Heat*, *Stepp Training*, *Arts Martiaux*, *Omnisports*, *Aqua-Training*, *Accompagnement individuel*, *Stages*, *Programmes*.
- **Icônes SVG Animées Sur-Mesure** : Kettlebell, basket/sneaker, gant de boxe, sphères omnisports, gouttes d'eau, chronomètre, montagne/drapeau, barre de charge.
- **Tape Marquees Défilantes** : Rubans hachurés athlétiques avec défilement fluide continu.
- **Cartes 3D à Rivets** : Section "# Choisis ton terrain de jeu" pour Particuliers, Entreprises et Territoires.
- **Dogtags Partenaires Flottants** : Bulles interactives animées pour les institutions, entreprises et associations de Grenoble et Isère.

---

## 🛠️ Démarrage Rapide

```bash
# 1. Installer les dépendances
npm install

# 2. Lancer le serveur de développement
npm run dev

# 3. Compiler pour la production
npm run build
```
